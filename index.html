公众号会重新处理图片。外链若有防盗链，或本地图片未被接收，请在公众号上传原图；本工具不会自动上传到微信素材库。

发布前检查

    复制结果采用内联样式。公众号可能调整样式、链接和图片，建议粘贴后发送手机预览，检查代码、表格、图片及全文。

    复制与图片说明

    复制的是排版后的富文本

    点击“复制到公众号”，再到公众号正文编辑区正常粘贴。不要使用“粘贴为纯文本”；文章标题需要填写到公众号单独的标题栏。

    代码与表格

    代码颜色和文字样式使用内联样式。默认开启代码换行，表格按正文宽度换行；列数很多时建议拆表或转图片。

    图片要在公众号中复核

    支持 HTTPS / HTTP 图片及本地 PNG、JPG、WebP、GIF。相对路径图片可在图片管理中替换。本地图片仅供当前页面预览；富文本携带 data 图片不代表公众号已接收，必要时在公众号上传原图。工具不保存账号，也不上传到素材库。

    离线、复制与保存

    双击可编辑和导出。富文本复制在 HTTPS 或 localhost 中支持更完整；不支持时会尝试选区复制。草稿保存默认关闭，开启后仅保存 Markdown 和排版设置，本地图片需重新选择。

    支持范围

    支持常见 Markdown、GFM 表格、任务列表和安全的基础 HTML。脚本、嵌入网页、音视频、SVG 会移除；数学公式和 Mermaid 不自动转图，请另行插入图片。
