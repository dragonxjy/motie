# 代码主题样例

用于检查代码配色、缩进、空行和横向滚动。以下代码仅展示排版，不会在网页中执行。

```jsx
import { useState } from "react";

export default function Counter() {
  const [count, setCount] = useState(0);

  // 手机宽度下保持原始代码行，可左右滑动查看。
  const message = "Markdown → 微信公众号：保留代码的颜色、缩进与原始换行";

  return (
    <section>
      <p>{message}</p>
      <button onClick={() => setCount(count + 1)}>已点击 {count} 次</button>
    </section>
  );
}
```
