## 真实浏览器验收

使用 Playwright 与系统 Chrome headless，通过本地静态服务器完成全部 17 组检查。记录见 [browser-checks.json](browser-checks.json)，真实页面截图见 [screenshots](screenshots/README.md)。

- 电脑默认显示 677 px 正文；在 1440、1280、1024、800 px 窗口下保持此宽度，窄面板允许横向查看，页面没有整体横向溢出。
- 手机模式在空间足够时模拟 375 px 屏幕和 343 px 正文；标签显示正文宽度，不计纸张留白。
- 三行长代码保持三行，代码块内部可用横向滚轮与左右方向键滚动，不撑宽文章；启用自动换行后不再横向溢出，关闭后恢复。
- 在 390 px 触摸设备模拟中，使用浏览器原生触摸事件左右滑动代码，确认代码滚动而文章不横移。
- 手机和电脑模式提交相同的富文本：含 677 px 正文上限、代码不折行与横向滚动内联样式；纯文本保留原始代码，复制结果不包含预览的键盘焦点标记。
- 默认代码主题按用户提供的公众号截图调整：深灰 `#282c34` 背景、红黄绿三色圆点、One Dark 配色、斜体注释、5 px 圆角和阴影，采用 13 px 等宽字体、25.5 px 行高。圆点为带内联样式的真实元素，复制时保留；代码滑动时顶部圆点保持原位。字体采用本机回退，不从远程加载字体。使用同一段 React 代码生成 [对照截图](screenshots/07-dark-code-theme.png)，样例见 [代码主题样例](代码主题样例.md)。
- 侧栏提供经典深色、清爽浅色、紫夜、午夜蓝四种代码配色，选择会保存。逐一通过复制按钮和 HTML 导出取得结果，在独立手机页面移除 CSS 优先级后进行原生触摸滑动：各主题都保留原始三行、三色圆点和横向滚动，正文不横移。见 [主题切换截图](screenshots/08-code-theme-switch.png)。

## 复现

使用 Node.js 24.15 或更新版本，在项目根目录执行：

```sh
npm ci
npm run check
npm test
npm run example
npx playwright install chromium
npm run test:browser
```

macOS 已安装 Chrome 时，可不下载 Chromium，改用：

```sh
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm run test:browser
```

网页运行不依赖测试包；直接打开 `index.html` 或运行 `npm start` 即可。
