# 截图与公众号验收

项目代码和自动化测试已完成；当前没有实际登录公众号、没有发送微信手机预览，也没有获得 TRAE 的真实操作截图。请完成下面的实际操作后记录结果，不要把工具内的预览当成公众号已经兼容的证明。

完整日常操作见 [使用说明](使用说明.md)。本文只记录浏览器、公众号验收和真实截图。

## 最短使用流程

1. 双击 `index.html`，或按部署说明打开 HTTPS 网页。
2. 保留默认示例，或粘贴含代码、图片、表格、列表的真实文章。
3. 查看手机与电脑预览，宽度上限分别为 375px、680px；窄面板会收缩。检查长代码行，确认预览不显示滚动条，同时滚轮、触控、键盘均可阅读到文章末尾。展开侧栏大纲点击标题，再使用返回顶部按钮。
4. 把一张截图复制到剪贴板，在文章中选好光标位置后粘贴；确认编辑区插入 Markdown 图片引用，预览显示对应图片。
5. 再用“图片管理”替换一个相对路径图片。
6. 点击“复制到公众号”，在空白公众号草稿的正文区普通粘贴。
7. 重新检查图片；如果丢失，使用公众号上传原图，然后重新预览。
8. 保存草稿并发送手机预览。这里只需要预览，不必公开发布文章。

## 本次分行问题复测

刷新工具页面后，导入 [公众号粘贴回归样例](公众号粘贴回归样例.md)，点击“复制到公众号”，在一个空白草稿里普通粘贴。请比较原始输入、工具预览和公众号粘贴结果：

| 检查位置 | 预期结果 |
| --- | --- |
| `request` 函数的参数 | 参数保持在原来的源代码行中，缩进和空行保留；手机宽度不足时允许自然折行 |
| 四条检查项 | ☑ / ☐ 与文字在同一段，不出现勾选符独占一段 |
| 已拆段的 Unicode 事项 | 勾选符与事项合并，后续补充说明仍是独立段落 |
| 12 条原有参考链接 | 编号保持 1–12，不再给这些条目追加另一组脚注，地址不重复拼接 |
| 自动生成的文末来源 | 每条一个段落，URL 标签不变成“URL：URL”；长 URL 可随阅读宽度自然折行 |
| 长文章切换字号、切换宽度、加载图片 | 预览内外均不显示滚动条，但可滚动到文章结尾；长代码仍可横向查看 |
| 侧栏新选项 | 段落间距切换生效；关闭图注后复制和导出也没有图注；大纲跳转到正确标题 |
| 光标处粘贴截图 | 图片引用插入在选区，不移动到文末；预览出现所复制的图片 |

复测时请用新复制的正文，不要只刷新旧公众号草稿。若仍有异常，保留该段 Markdown、粘贴后的截图和浏览器版本，便于确定发生变化的元素。
