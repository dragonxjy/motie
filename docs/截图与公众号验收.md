# 截图与公众号验收

项目代码和本地验证已完成，并已只读定位当前 Chrome 中的公众号编辑器；尚未写入公众号草稿或发送微信手机预览，也没有获得 TRAE 的真实操作截图。请完成下面的实际操作后记录结果，不要把工具内的预览当成公众号已经兼容的证明。

完整日常操作见 [使用说明](使用说明.md)。本文只记录浏览器、公众号验收和真实截图。

## 最短使用流程

1. 双击 `index.html`，或按部署说明打开 HTTPS 网页。
2. 保留默认示例，或粘贴含代码、图片、表格、列表的真实文章。
3. 查看手机与电脑预览：375px 手机屏幕对应 343px 正文，电脑正文固定 677px，标签不含纸张留白。窄电脑面板可左右移动查看全文。长代码默认不折行，使用代码块底部滚动条、触控板或左右方向键查看，手机上直接左右滑动；确认不会撑宽正文。展开侧栏大纲点击标题，再使用返回顶部按钮。
4. 把一张截图复制到剪贴板，在文章中选好光标位置后粘贴；确认编辑区插入 Markdown 图片引用，预览显示对应图片。
5. 再用“图片管理”替换一个相对路径图片。
6. 点击“复制到公众号”，在空白公众号草稿的正文区普通粘贴。
7. 重新检查图片；如果丢失，使用公众号上传原图，然后重新预览。
8. 保存草稿并发送手机预览。这里只需要预览，不必公开发布文章。

## 本次分行问题复测

刷新工具页面后，导入 [公众号粘贴回归样例](公众号粘贴回归样例.md)，点击“复制到公众号”，在一个空白草稿里普通粘贴。请比较原始输入、工具预览和公众号粘贴结果：

| 检查位置 | 预期结果 |
| --- | --- |
| `request` 函数的参数 | 参数保持在原来的源代码行中，缩进和空行保留；手机宽度不足时在代码块内左右滑动，默认不折行 |
| 默认代码外观 | 深灰底、红黄绿圆点、彩色语法、斜体注释、圆角与阴影；滑动代码时圆点保持原位 |
| 四条检查项 | ☑ / ☐ 与文字在同一段，不出现勾选符独占一段 |
| 已拆段的 Unicode 事项 | 勾选符与事项合并，后续补充说明仍是独立段落 |
| 12 条原有参考链接 | 编号保持 1–12，不再给这些条目追加另一组脚注，地址不重复拼接 |
| 自动生成的文末来源 | 每条一个段落，URL 标签不变成“URL：URL”；长 URL 可随阅读宽度自然折行 |
| 长文章切换字号、切换宽度、加载图片 | 文章预览隐藏纵向滚动条，仍可滚动到结尾；代码块显示细横向滚动条，长行可左右查看 |
| 侧栏新选项 | 段落间距切换生效；关闭图注后复制和导出也没有图注；大纲跳转到正确标题 |
| 光标处粘贴截图 | 图片引用插入在选区，不移动到文末；预览出现所复制的图片 |

复测时请用新复制的正文，不要只刷新旧公众号草稿。若仍有异常，保留该段 Markdown、粘贴后的截图和浏览器版本，便于确定发生变化的元素。

## 浏览器脚本

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

脚本通过后生成 `docs/browser-checks.json` 和 `docs/screenshots/01-workspace.png` 至 `09-article-styles.png`。第六张来自没有墨贴 CSS/JS 的独立手机页面，用于验证复制 HTML 自带主题和触摸滑动样式；第七张使用原文章中的 React 代码对照深色主题；第八张展示侧栏切换代码配色；第九张展示九种文章版式。17 组检查包括去除 CSS 优先级和内在宽度后的清洗回归样例、全部代码主题的复制与导出以及手机触摸滑动。脚本不打开 TRAE，不登录公众号；它的复制测试使用接口替身，不能替代公众号验收。另已单独在有界面 Chrome 中完成系统剪贴板的真实复制与本地原生粘贴，见 [clipboard-check.json](clipboard-check.json)。

2026-11-04 已使用系统 Chrome 156.0.8078.81 完成浏览器验收，生成上述九张截图与 [browser-checks.json](browser-checks.json)。检查包括电脑固定正文宽度、手机触摸滑动代码、键盘与横向滚轮、独立页面中的代码主题与三色圆点、圆点固定、文章样式切换和 HTML 导出。已只读定位公众号编辑器，因该窗口禁止页面脚本且用户选择先完成本地验证，没有写入公众号草稿。
