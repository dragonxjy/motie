# 墨贴使用说明

适用版本：1.1.0。墨贴把 Markdown 转为带排版的富文本，供你复制到微信公众号正文编辑区。默认主色为 `#1c8feb`。

## 1. 打开工具

- **直接打开**：双击项目中的 `index.html`，即可编辑、预览和导出。
- **本机地址**：在 `motie` 文件夹打开终端，运行 `node serve.cjs` 或 `npm start`，访问终端显示的地址，默认是 `http://127.0.0.1:4180`。需要 Node.js 24.15 或更新版本，启动网页不用安装依赖。
- **在线使用**：部署到 GitHub Pages 后访问 HTTPS 地址，步骤见 [部署说明](DEPLOY.md)。

如果直接打开文件后复制失败，优先改用 localhost 或 HTTPS 页面。

## 2. 粘贴或导入 Markdown

在左侧编辑区粘贴全文，右侧会自动更新排版。编辑区上方的文件按钮可以导入 `.md`、`.markdown` 或 `.txt`，也可以直接拖入文件。替换已有内容时会先提示确认，误操作可用撤销恢复。

常用写法：

````markdown
# 文章标题

## 小节标题

正文支持 **加粗**、*斜体*、`行内代码`。

> 这里是一段引用。

- 普通列表
- [x] 已完成事项
- [ ] 待办事项

```javascript
function request(path, options = {}) {
  return fetch(path, options);
}
```

![架构示意](https://example.com/diagram.png)

[Vue 文档](https://cn.vuejs.org/)
````

上面的图片地址仅是写法示例，请替换为自己的图片。代码围栏后可写 `javascript`、`python`、`json` 等语言；没有识别到的语言按普通代码显示。

## 3. 调整排版

电脑上右侧为排版侧栏。窄窗口和手机上点击“排版”打开，按 `Esc` 关闭；点击大纲标题也会自动回到正文预览。

| 控件 | 用途 |
| --- | --- |
| 文章样式 | 简洁、书刊、技术、杂志、雅致、清新、水墨、卡片、极简九种版式，下方说明各版式特点 |
| 主题色 | 默认晴空蓝，可选预设色或自定义；影响文章标题、引用和强调等 |
| 字号 | 13–20 px，默认 16 px |
| 行距 | 紧凑、标准、宽松、加宽，默认 1.85 |
| 段落间距 | 12、18、24 px，默认 18 px；引用与列表末段保持紧凑 |
| 代码块主题 | 经典深色、清爽浅色、紫夜、午夜蓝；独立于文章样式，切换配色时保留横向滚动 |
| 代码自动换行 | 默认关闭，保留源代码行，长代码可左右滚动；勾选后按正文宽度折行 |
| 外链转为文末注释 | 默认开启，相同 URL 合并，已有编号参考资料保留原编号 |
| 正文隐藏首个一级标题 | 避免公众号标题栏与正文重复；其他标题保留 |
| 图片下显示说明文字 | 默认开启，以图片的替代文本作为图注；关闭后复制和导出也移除图注，图片本身保留 |
| 文章大纲 | 展开查看各级标题，点击定位到预览中的对应位置 |
| 图片管理 | 查看图片、替换路径、下载当前页的本地原图 |
| 发布前检查 | 查看图片、链接和未支持内容等提示 |
| 重置样式 | 侧栏标题旁的重置按钮，恢复默认排版，不替换正文 |

排版选项会自动保存在当前浏览器。旧版默认绿色会迁移为蓝色，已选择的其他颜色继续保留。工具界面的主色保持蓝色，文章主题色可以单独调整。旧设置首次迁移时会关闭代码自动换行，其他排版参数和草稿保留；之后手动选择的换行偏好会正常保存。

文章样式与代码主题可以自由搭配：杂志使用醒目标题和粗分隔线，雅致使用居中标题与细线，清新使用柔和底色与圆角，水墨使用衬线字体和墨色线条，卡片使用带边框的标题和引用，极简突出留白。切换文章样式保留已选的主题色、代码配色和换行偏好。

## 4. 查看手机和电脑效果

电脑打开时默认使用公众号电脑阅读宽度预设：正文固定为 **677 px**，纸张留白另计。三栏布局优先为预览保留空间，窄窗口中的排版侧栏改为弹层；面板仍不足时可在预览区左右移动，正文不被压窄。复制与导出的正文采用相同的 677 px 宽度上限，目标容器更窄时自适应。

手机按钮模拟 375 px 屏幕，左右各留 16 px，正文为 **343 px**；面板更窄时会继续收缩。顶部标签始终显示实际正文宽度，不包含纸张留白。最终效果仍应查看公众号提供的真实预览。

**预览不显示滚动条，但仍可以滚动。** 使用鼠标滚轮、触控板或手机滑动阅读全文；键盘用户可聚焦预览后使用方向键、Page Up / Page Down。顶部向上箭头可返回文章开头。文章没有嵌入的第二层纵向滚动视口。

代码默认使用经典深色主题，保留所提供截图的深灰圆角代码框、红黄绿三色圆点、彩色语法高亮和斜体注释，采用 13px 等宽字与 25.5px 行高。侧栏可切换清爽浅色、紫夜、午夜蓝，各主题都使用同一滚动结构。长行在代码块内左右移动，不会撑宽正文，顶部圆点保持原位。可以使用触控板横向滑动、拖动底部的细滚动条，或聚焦代码块后按左右方向键；手机上直接左右滑动。“复制到公众号”与 HTML 导出同时携带所选配色、圆点、阴影和滚动样式。需要折行时，勾选“代码自动换行”。可导入 [代码主题样例](代码主题样例.md) 对照截图。更新工具后需要重新复制正文，旧公众号草稿中的内容不会自动更新。

此版首次载入会把旧版的代码换行设置切换为关闭，避免旧设置继续影响公众号粘贴；其他排版设置和草稿保留。以后手动开启“代码自动换行”仍会被记住。复测请删除草稿中的旧正文，再用“复制到公众号”普通粘贴，保存后重新生成手机预览。

## 5. 插入和替换图片

### 在光标处粘贴图片

1. 复制一张图片或截图。
2. 在左侧 Markdown 正文中把光标放到插图位置，也可以选中需要替换的文字。
3. 按 `⌘V`（macOS）或 `Ctrl+V`（Windows）。
4. 编辑区会插入 `![图片说明](motie-local-...)`，预览显示图片。

也可点编辑区图片按钮选文件，或将图片拖到编辑区。支持 PNG、JPG、WebP、GIF；单张最大 5 MB，一次最多处理 20 张。修改 `![这里的文字](...)` 可以修改图片说明，侧栏图注开关控制是否显示说明文字。

### 处理已有的相对路径

`![架构图](./images/architecture.png)` 只有路径，网页无法自动读取你电脑里的文件。点击侧栏“图片管理”，找到该项后：

- 点替换按钮选择原图；或
- 填写可访问的完整 HTTP / HTTPS 图片地址，再点确认按钮。

替换仅更新当前页的图片映射，原始 Markdown 路径保留。当前没有按文件名批量匹配功能。

### 保存图片和公众号接收

**本地图片只存在于当前页面，刷新前请做好备份。** “保存本机草稿”和“下载 Markdown”都不打包本地图片；刷新后需重新选图。带图备份请选择导出 HTML，或者在图片管理中下载原图并单独保存。

预览中图片能显示，不代表公众号已接收。公众号可能拒绝外链、防盗链图片或内嵌 `data:` 图片。粘贴后逐张检查；缺图时在公众号上传原图。墨贴不上传微信素材库，也不获取公众号账号或凭证。

## 6. 复制到微信公众号

1. 检查预览，必要时打开“发布前检查”。
2. 点击右上角 **复制到公众号**，等待“已复制”提示。
3. 打开公众号草稿，在**正文编辑区普通粘贴**，使用 `⌘V` / `Ctrl+V`。
4. 将文章标题填到公众号独立的标题栏；不要使用“粘贴为纯文本”。
5. 逐项检查代码、任务列表、表格、图片和参考链接。
6. 发送一次公众号手机预览，再决定是否发布。

复制内容是 HTML 富文本，同时附带纯文本。代码的换行、缩进和内联高亮、列表和引用等都会进入这份结果；目标平台仍可能重新处理样式。工具不自动登录或发布文章。

## 7. 保存和导出

| 方式 | 保存什么 | 适合什么时候 |
| --- | --- | --- |
| 保存本机草稿 | Markdown，位于当前浏览器；默认关闭，取消勾选会移除所存草稿 | 在同一浏览器继续编辑 |
| 下载 Markdown | 原始正文，不包含本地图片资源，也不包含临时图片替换映射 | 版本管理、文字备份 |
| 导出 HTML | 当前排版结果及当前页内嵌的本地图片 | 带图备份、离线阅读、复制失败时使用 |
| 图片管理中下载原图 | 当前页所选的本地图片 | 独立保存图片 |

“下载 Markdown”位于编辑区上方的“更多”菜单；HTML 导出位于预览顶部下载按钮。HTML 与复制正文使用同一份转换结果。草稿只在当前浏览器 / 地址下保存，不会跨设备同步，清理浏览器数据后可能丢失。

编辑区支持工具栏撤销 / 重做，或 `⌘Z` / `Ctrl+Z`、`⌘⇧Z` / `Ctrl+Shift+Z`。按 `Tab` 插入两个空格。

## 8. 内容支持与常见问题

支持一级至六级标题、正文强调、引用、嵌套列表、任务列表、代码块、GFM 表格、图片、普通和参考式链接，以及清理后的基础 HTML。

### 复制后只有纯文本，或浏览器拒绝复制

确认是在公众号正文中普通粘贴；尽量用 Chrome / Edge 的 HTTPS 或 localhost 页面。若仍失败，先导出 HTML，在浏览器打开，选中正文再复制。复制失败时工具会提示，不会冒充成功。

### 参数、长网址或表格换行

代码会保留原始换行和缩进；自动折行只是窄屏显示行为，参数中不会额外插入段落。长 URL 也会按阅读宽度自然折行。过多列表嵌套或多列表格建议精简；八九列的表格优先拆分或转图片，不要只缩小字号。

若公众号中出现额外段落，用 [回归样例](公众号粘贴回归样例.md) 在空白草稿重新粘贴，保留该段 Markdown 和粘贴后的截图，便于比较。

### 导入后图片缺失

相对路径需要手动匹配；关闭页面后本地图片也需重新选择。外链不能加载时检查地址和来源权限，或在图片管理中换成本地原图。

### 数学公式、Mermaid、SVG 和音视频

数学公式与 Mermaid 暂不渲染，请自行转图后插入。SVG、脚本、嵌入网页和音视频不会作为公众号正文内容保留，输入中的原始 class、style、脚本和事件会清理。

### 本机草稿保存失败

浏览器隐私模式、本地文件模式或存储空间不足可能限制保存。先下载 Markdown，再导出带图 HTML。导入文件上限 2 MB，正文上限 30 万字符；过大的内嵌图片建议压缩后插入。
