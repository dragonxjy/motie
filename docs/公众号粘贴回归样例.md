# 公众号粘贴格式复测

## 01 函数参数、缩进和空行

下面是格式样例，不会在页面执行。第一行参数应保持在同一源代码行，手机上较长时应在代码框内左右滑动，不自动折行。

```javascript
async function request(path, { method = "GET", timeout = 5000 } = {}) {
  const params = {
    page: 1,
    query: "<a>&b",
    enabled: true
  };

  return send(path, { method, timeout, params });
}
```

未知语言也应保留缩进和换行：

```example
example --name="a b"
    --timeout=1000

    --output="result.json"
```
