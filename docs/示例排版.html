Markdown 文章发布前检查

正文先写在 Markdown 文件里，发布前再检查标题、代码、图片和表格。公众号会重新处理复制过来的富文本，所以这份预览还需要拿到草稿里实际粘贴一次。

浏览器里能看到图片，不代表公众号已经接收了它。

标题和正文

标题层级沿用原稿。命令和变量名用行内代码标出，例如 npm run build。

代码块

长代码保留原始换行，可在代码块内左右滑动查看。对照原文时，检查参数顺序、缩进和空行。

   
async function fetchUsers(page, { active = true, pageSize = 20 } = {}) {
  const params = { page, active, pageSize };

  return request("/api/users", { params });
}

检查清单

内容 原稿中写法 发布前看什么
标题 一级标题 标题栏是否已填写
代码 围栏代码块 缩进、参数和长行
图片 Markdown 图片 粘贴后是否显示
